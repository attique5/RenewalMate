# RenewalMate

**Never Miss a Renewal Again.**

RenewalMate is a modern Android application designed to help individuals and businesses manage important document expiry dates and renewals in one convenient place.

## Key Features

- Track document expiry dates.
- Receive advance renewal reminders.
- Manage multiple documents.
- View remaining days until expiration.
- Color-coded document status:
  - 🟢 Valid
  - 🟠 Expiring Soon
  - 🔴 Expired
- Clean and modern user interface.
- Simple document management.
- Lightweight application design.

## Supported Document Categories

- Passport
- National ID / Resident Card
- Driving License
- Visa
- Vehicle Registration
- Insurance Policies
- Commercial Registration
- Business Licenses
- Certificates
- Subscriptions
- Custom Documents
